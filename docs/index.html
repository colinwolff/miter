Five pillars

Context window savings

An agent reads a whole 800-line file just to see its signatures.

miter skeleton returns signatures and line numbers; miter lookup fetches one symbol plus its neighbours.

Safe modularity slicing

Splitting a bloated file by hand yields circular imports and missing pub modifiers.

miter slice names the seam and the exact pub(crate) elevations; miter audit holds the ceiling.

Cross-stack type contracts

A new SQL column and Rust field, but the TypeScript interface never got it.

miter contracts compares SQL tables, Rust structs and TypeScript interfaces field by field.

Reverse call-graph impact

grep returns noisy comments, unrelated substrings and misses multi-hop callers.

miter impact walks the reverse call graph and lists the tests to run, with their commands.

AST-aware secret redaction

An agent reading .env, a Dockerfile or a manifest pulls raw credentials into the prompt.

Every signature, body and MCP response is scrubbed: keys, sk_live_... tokens and high-entropy strings become [REDACTED_SECRET].
